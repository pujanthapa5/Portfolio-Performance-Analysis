# Portfolio Performance Analysis

## Project Overview

This project analyzes a product portfolio using Microsoft Excel to evaluate revenue, profitability, revenue share, profit share, and product distribution.

## Objectives

- Identify high-performing portfolios
- Detect underperforming products
- Recommend strategic business actions

## Tools Used

- Microsoft Excel
- Pivot Tables
- SUMIF
- COUNTIF
- Structured Tables
- Dashboard Design
